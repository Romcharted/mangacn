# Third-party marks (showcase only)

These files are used only by the showcase demo of the Auth example and of `SocialButton`. They are **not**
part of any registry item: `SocialButton` ships a logo slot and no logo. Each mark belongs to its owner and is
used unmodified, under that owner's brand rules; it is not covered by this repository's MIT licence.

| File | Source | Rules |
| --- | --- | --- |
| `google-g.png` | The standard full-colour Google "G" on a transparent background, supplied by the project owner; the file is not modified | <https://developers.google.com/identity/branding-guidelines>: the "G" is never recoloured, redrawn or shown without a label. Google asks for it on a white background; the showcase shows it on the button's own paper (and on ink in dark mode) by the project owner's choice. |
| `apple-logo-black.png` | Official Apple logo, black on a transparent background, supplied by the project owner; the file is not modified | <https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple>: the Apple logo in black or in white only, never redrawn, recoloured otherwise or shown without a label. In dark mode the showcase shows this file white (CSS `invert`: colour only, the drawing untouched). |

The Google "G" keeps its official colours: this is the one exception to the kit's single-accent rule, limited to
the logo slot of a third-party sign-in button (approved by the project owner).
